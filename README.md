# 🍉 Arbuz Bot

Discord-бот для ежедневной лотереи роли **АРБУЗ**. Каждый день участники сервера кидают кубик d20, и тот, кто выбросил наибольшее число, получает почётную роль.

---

## Команды

| Команда | Описание |
|---|---|
| `!arbuz` | Бросить d20 на сегодня |
| `!да` | Запустить **арбузную анархию** (только если выпал 1) |
| `!нет` | Отказаться от анархии и оставить 1 |
| `!top` | Текущий лидерборд за сегодня |
| `!setrole arbuz @Роль` | Назначить роль победителя (требует право Управление ролями) |
| `!setrole tykvenets @Роль` | Назначить роль проигравшего |
| `!setrole` | Показать текущие настройки ролей |

---

## Механика игры

### Обычный бросок — `!arbuz`

Бот бросает кубик d20 (случайное целое от 1 до 20).

- Бросить можно только **один раз в день** (день считается по МСК).
- Результат немедленно финализируется и попадает в лидерборд.
- Исключение: выпавшая **1** не финализируется сразу — игроку предлагается арбузная анархия.

### Выпала 1 — арбузная анархия

Если выпало **1**, бот предлагает сделать повторный бросок в режиме анархии:

```
!да  — перебросить кубик (режим анархии)
!нет — оставить 1 и финализироваться в обычном режиме
```

На решение даётся **1 час**. Если за это время ни `!да`, ни `!нет` не поступило — бросок автоматически финализируется как **1 в обычном режиме**.

**Режим анархии (`!да`):**
- Бросается новый d20.
- Результат отображается в отдельной таблице `!top` и **не участвует** в розыгрыше роли АРБУЗ.
- Если в анархии выпало **20** — роль АРБУЗ за этот день **не получает никто**, все становятся тыквенцами.

### Закрытие дня

Каждый день в **23:59 МСК** бот подводит итоги:

1. Все незакрытые броски (выбросили 1, но не ответили `!да`/`!нет`) автоматически финализируются как **1 в обычном режиме**.
2. Определяется победитель среди **обычных** бросков (анархия не учитывается).
3. Результат объявляется в канале, роли **назначаются автоматически** через Discord API.

### Определение победителя

| Ситуация | Результат |
|---|---|
| Один игрок с максимальным значением | Получает роль **АРБУЗ** |
| Никто не делал обычный бросок | Все получают роль **тыквенца** |
| В анархии выпало **20** | Роль АРБУЗ не выдаётся, все — тыквенцы |
| Ничья между несколькими игроками | Запускается **тай-брейк** |

### Тай-брейк

Если у нескольких игроков одинаковый максимальный результат:

1. Бот объявляет тай-брейк и перечисляет участников.
2. Роль АРБУЗ пока остаётся у **прошлого** владельца.
3. Участники тай-брейка кидают `!arbuz` повторно — эти броски засчитываются в тай-брейк, а не в обычный день.
4. Дедлайн тай-брейка — следующий день в **12:00 МСК**.

**Исходы тай-брейка:**

| Ситуация | Результат |
|---|---|
| Один победитель | Получает роль **АРБУЗ** |
| Повторная ничья | Роль никому, все — **тыквенцы** |

## Лидерборд — `!top`

Показывает текущее состояние дня:

- ⏳ Игроки, которые ещё не ответили `!да`/`!нет`
- 🍉 Таблица обычных бросков (участвуют в розыгрыше роли), отсортированная по убыванию
- 🎲 Таблица анархийных бросков (отдельно, в розыгрыше не участвуют)
- 🔢 Распределение обычных бросков по значениям 1–20
- ⚔️ Статус активного тай-брейка (если есть)

## Технологии

- **Runtime:** Node.js 20, TypeScript
- **Discord:** discord.js v14
- **БД:** PostgreSQL 16 + Drizzle ORM
- **Инфраструктура:** Docker Compose
- **CI/CD:** GitHub Actions (деплой при пуше в `main`)
